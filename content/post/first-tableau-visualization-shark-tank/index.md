##  Beneath the Tank: A Quick Dive into the World of Shark Tank USA

This university assignment involved preparing the data in Excel and creating the visualization in Tableau. The goal was hands-on practice with visualization best practices, so the analysis is intentionally descriptive rather than practical.

As my first Tableau project, I focused on adding interactive elements such as Top N filters, seasonal filters, chart switching, and map highlighters. I strongly encourage you to check out the live preview!

These filters were created using dedicated parameter setups, feel free to explore the configuration directly in Tableau after the image gallery.
